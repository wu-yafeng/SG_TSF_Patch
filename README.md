# SG_TSF_Patch

QQ三国输入法补丁，用于修复新版本 Windows 下游戏内输入法行为异常的问题。

## 项目简介

在 Windows 8.1 及之后的系统中，系统输入法管理机制从传统 IME 逐步转向 TSF（Text Services Framework）。QQ三国仍然依赖较老的输入法交互方式，因此在游戏过程中经常出现以下问题：

- 放技能、移动或战斗时意外弹出输入法
- 需要频繁按 `Shift` 手动切换中英文
- 打字和游戏操作互相干扰

本项目通过启动器配合补丁 DLL 的方式，在游戏运行时调整输入法启用逻辑，让游戏中的输入体验更接近 Windows 7 时代的表现。

## 功能特性

- 自动启动 QQ三国并注入补丁
- 优化游戏内输入法启用/关闭时机
- 减少战斗过程中误触发输入法的问题
- 保留聊天、输入等正常文字输入场景
- 开箱即用，无需手动修改游戏文件

## 适用环境

- 操作系统：Windows 8.1 / Windows 10 / Windows 11
- 游戏：QQ三国
- 权限要求：建议使用管理员权限运行 `BootMain.exe`

> Windows 7 及以下系统通常不需要此补丁，也不建议使用。

## 使用方法

### 方式一：直接下载发布版

1. 打开 [Releases](https://github.com/wu-yafeng/SG_TSF_Patch/releases)
2. 下载最新发布的压缩包或二进制文件
3. 解压到一个路径简单、尽量全英文的目录
4. 确保目录中至少包含以下文件：
   - `BootMain.exe`
   - `TSF_Patcher.dll`
5. 以管理员身份运行 `BootMain.exe`
6. 程序会自动读取 QQ三国安装目录并启动游戏

### 方式二：自行编译

开发环境要求：

- Visual Studio 2022 或更新版本
- 已安装 C++ 桌面开发组件
- Windows SDK

编译步骤：

1. 使用 Visual Studio 打开 `SG_TSF_Patch.sln`
2. 选择 `Release` 配置
3. 选择 `x86` 平台
4. 编译整个解决方案
5. 在输出目录中获取：
   - `BootMain.exe`
   - `TSF_Patcher.dll`

## 工作原理

项目包含两个主要部分：

- `BootMain`：启动器，负责读取游戏安装路径并启动游戏进程
- `TSF_Patcher`：补丁 DLL，负责在游戏运行过程中接管与输入法相关的逻辑

启动器会先创建游戏进程，再将补丁 DLL 注入到游戏中，从而在需要输入文字时启用输入法，在普通游戏操作时尽量避免输入法干扰。

## 常见问题

### 1. 提示“找不到游戏目录”

程序会从注册表中读取 QQ三国安装路径。如果提示找不到目录，请确认：

- QQ三国已经正确安装
- 游戏安装信息已经写入系统注册表
- 当前系统用户与游戏安装用户一致

### 2. 提示“找不到 dll 文件”

请确认 `TSF_Patcher.dll` 与 `BootMain.exe` 位于同一目录下。

### 3. 为什么建议放在全英文目录？

这样可以降低路径编码、权限或兼容性带来的额外问题，便于稳定运行和排查异常。

## 注意事项

- 本项目仅用于修复输入法相关兼容性问题
- 请勿随意修改发布包中的文件名或目录结构
- 若安全软件拦截注入行为，请先确认文件来源并自行判断风险
- 补丁可能会因游戏版本变化而失效

## 卸载

删除补丁目录即可。如不再需要，直接删除 `BootMain.exe` 和 `TSF_Patcher.dll` 即可完成卸载。
